Password strength checker

Type a password to see how it scores. Everything runs in your browser: nothing you type is stored or sent anywhere. Do not test a password you actually use.

Start typing to check strength.

  • At least 12 characters
  • An uppercase letter
  • A lowercase letter
  • A number
  • A symbol such as ! ? # %
  • Not a common password or pattern

Tips

  • A long passphrase of several unrelated words beats a short complex password.
  • Use a different password for every account, and a password manager to remember them.
  • Turn on two-factor authentication wherever it is offered.
